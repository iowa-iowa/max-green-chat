# MAX Chat — согласованное решение

React + TypeScript + Vite, CSS, fetch. Самостоятельный frontend без сервера и БД.
Пользователь вводит idInstance, apiTokenInstance и apiUrl из кабинета GREEN-API.
Проверка состояния инстанса перед открытием чата. Данные доступа только в памяти.
Две панели по образцу веб-MAX: чаты и переписка. На мобильном одна панель и возврат.
Новый чат по международному номеру, CheckAccount возвращает реальный MAX chatId.
SendMessage отправляет только текст до 4000 символов. Входящие через последовательный
ReceiveNotification → обработка → DeleteNotification; отмена запросов при выходе.
Повторное уведомление не дублирует сообщения. Неизвестные типы подтверждаются и пропускаются.
Никаких файлов, звонков, группового управления или отдельной авторизации сайта.
Токен и история не переживают перезагрузку. Это явно описано в интерфейсе и README.
README содержит подготовку инстанса, запуск, ограничения и ручной сценарий двух устройств.
Проверки: unit-тесты нормализации, reducer, API, polling; браузерный сценарий с mock HTTP API.
Реальная проверка с MAX требует пользовательского инстанса и второго аккаунта.

Дизайн: светлый фон #f5f7fb, белые панели, акцент #1677ff, текст #202939,
вторичный #68758a, разделители #e9edf3. Системная типографика Segoe UI.
Структура Workbench, боковая навигация; бренд MAX имеет приоритет над темами навыков.
