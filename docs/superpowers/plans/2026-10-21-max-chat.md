# План реализации чата MAX

**Цель:** Рабочий React-чат для текстовой переписки в MAX через GREEN-API.
**Архитектура:** API-клиент изолирует fetch и проверку ответов; reducer хранит чаты;
последовательный polling обрабатывает уведомления. React-компоненты отвечают за формы и отображение.
**Технологии:** React, TypeScript, Vite, CSS, Vitest, Playwright.

## Ограничения
Только текст, React, MAX, SendMessage и HTTP API получения. Токен только в памяти.
Реализация в этой сессии, отдельная директория нового проекта. Публикация GitHub/хостинга отдельным шагом.
